# agile-final-project

## Description
This project demonstrates Agile development practices by creating a simulated product backlog for an e-commerce product catalog service. I created 10 user stories with acceptance criteria in Gherkin syntax, organized them on a GitHub kanban board, and conducted backlog refinement to prioritize requirements. I then planned a 2-week sprint by selecting the top 4 stories, assigned story points, and simulated sprint execution by moving stories through workflow stages. This exercise showcases practical application of Scrum methodology including product backlog management, sprint planning, and kanban board workflow.
